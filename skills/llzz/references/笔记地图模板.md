# 笔记地图

> 本页是 AI 读写本 vault 的规则大脑。AI 每次读写笔记前必须先读本页。

## 入口

- [[分类A/README|分类A]]
- [[分类B/README|分类B]]

## 分类规则

- 分类A：<这个分类放什么内容>，全部进 `分类A/`。
- 分类B：<这个分类放什么内容>，全部进 `分类B/`。
- 同一前缀的文档放入同名二级目录，避免大量扁平文件堆在入口目录。
- 本页只做入口和规则，不放正文内容。

## 写入偏好

- **极简原则：只记核心——关键事实、结论、待办。不写背景、不扩写、不润色、不总结。**
- 随手记默认 3-5 行以内；能一行说清的不分点。
- 待办用 `- [ ]` 提取。
- 身体不适、重要风险、强时间敏感事项使用 Obsidian callout。
- 不新增顶级分类；归不进现有分类时归入最接近的分类并告知用户。

## 安全规则

- 普通笔记正文不记录 API key、token、密码、证书私钥等敏感值。
- 需要敏感值时只写存放位置或 key 名。
- AI 默认先读本页，再读对应目录的 README。除非用户明确要求，不读取私密配置目录。
