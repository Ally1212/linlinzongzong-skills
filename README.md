# llzz-skill

`llzz-skill` 是一个给 Codex 使用的本地技能项目，用来把零散记录轻量整理后写入本地 Obsidian vault 的“林林总总”目录。

它的核心目标是：当用户说“林林总总”或 `llzz` 时，AI 不只是机械追加，而是先阅读现有笔记，判断这条记录应该追加到相关旧文件，还是新建一个更合适的主题文件。

## 项目定位

这个项目保存 `llzz` 技能的源文件。安装后，Codex 可以在以下场景自动使用它：

- 快速保存生活随手记。
- 整理截图中的笔记内容。
- 归档健康、饮食、健身、装修、复盘等碎片记录。
- 根据主题把新记录放进 Obsidian 的合适文件。
- 当旧文件过大时，自动拆成新文件，避免单个笔记越来越臃肿。

默认写入的 Obsidian 目录是：

```text
/Users/ziheng/Library/Mobile Documents/iCloud~md~obsidian/Documents/笔记个人/林林总总
```

## 目录结构

```text
llzz-skill/
├── README.md
├── scripts/
│   └── install.sh
└── skills/
    └── llzz/
        ├── SKILL.md
        └── agents/
            └── openai.yaml
```

说明：

- `skills/llzz/SKILL.md` 是技能主体，包含触发条件、工作流、文件选择规则和写入格式。
- `skills/llzz/agents/openai.yaml` 是技能的 UI 元数据，用于展示名称、简介和默认 prompt。
- `scripts/install.sh` 用于把项目里的技能安装或同步到本机 Codex 技能目录。

## 触发条件

技能应在用户表达“要记录到林林总总”时触发。

典型触发语：

```text
林林总总：今天晚上去健身了，练了背，感觉状态还行。
```

```text
llzz 记一下：今天肚子有点撑，早点睡，明天少吃点。
```

```text
把这个截图整理到林林总总
```

```text
记到林林总总：爸妈今天来看装修，聊了一些细节。
```

不应该触发的情况：

- 用户只是解释“林林总总”这个词，没有归档意图。
- 用户明确要求写入其他 Obsidian 目录。
- 用户要求严格专业分析，但没有要求保存记录。

## 核心行为

`llzz` 技能的行为分为四步：

1. 读取用户当前给出的内容。
2. 扫描 Obsidian 的“林林总总”目录。
3. 根据主题相关性和文件大小判断写入目标。
4. 轻量整理为 Obsidian Markdown，并追加或新建文件。

技能必须遵守这些原则：

- 只整理当前用户提供的内容，不混入历史会话。
- 保留原意和现场感，不拔高、不扩写成报告。
- 能分点就分点，能简洁就简洁。
- 自动提取待办事项。
- 对身体不适、重要风险、强时间敏感事项使用 Obsidian callout。
- 不覆盖旧笔记，只能追加或新建。

## 文件选择逻辑

技能的关键能力是自动判断“追加旧文件”还是“新建文件”。

### 优先追加旧文件的情况

当新内容和某个旧文件强相关，并且旧文件没有过大时，应该追加到旧文件。

强相关信号包括：

- 同一主题：例如健康饮食、腹胀打嗝、健身训练、装修、五一总结。
- 同一实体：例如同一个人、地点、项目、医院、健身房。
- 同一连续事件：例如同一趟旅行、同一段装修进展、同一个健康问题。
- 用户明确说“补充到上次那个”“接着昨天的”。

追加位置建议：

- 如果旧文件中有同名或相近二级标题，追加到该标题下。
- 如果没有明显标题，追加到文件末尾的新时间块。

### 应该新建文件的情况

当满足任一条件时，新建文件：

- 没有明显相关旧文件。
- 新内容是一个完整的新主题。
- 追加会让旧文件主题变杂。
- 相关旧文件已经过大。
- AI 无法可靠判断应该追加到哪个文件。

默认新文件命名：

```text
YYYY-MM-DD 简短主题.md
```

如果内容很碎、无法稳定命名：

```text
YYYY-MM-DD 林林总总.md
```

### 文件大小阈值

当前规则：

- `80 KB` 以上：硬阈值，必须新建文件。
- `60 KB` 以上：软阈值，如果当前内容较长或能独立成篇，优先新建。
- `60 KB` 以下：主要看主题相关性。

设计原因：

- 避免单个笔记过长，影响 Obsidian 阅读和检索。
- 避免“林林总总”目录变成一个巨型流水账。
- 让同一主题保持连续，又不会无限膨胀。

## 笔记格式

### 新建主题文件

```markdown
---
title: 2026-05-12 简短主题
date: 2026-05-12
tags:
  - 生活记录
---

# 2026-05-12 简短主题

## 核心整理

- ...

## 待办

- [ ] ...

## 原始记录

> ...
```

### 追加到已有文件

```markdown
## 14:30｜简短标题

### 简要整理

- ...

### 待办

- [ ] ...

### 原始记录

> ...
```

### 很短的随手记

```markdown
## 14:30｜随手记

- ...
```

## 示例

输入：

```text
llzz 今天晚上去健身了，练了背，高位下拉和划船，感觉比上次有力气一点。
```

如果已有健康健身相关文件且未超过大小阈值，技能可能追加：

```markdown
## 21:40｜健身记录

### 简要整理

- 晚上去健身，主要练背。
- 动作包括高位下拉和划船。
- 主观感受：比上次更有力气。

### 原始记录

> 今天晚上去健身了，练了背，高位下拉和划船，感觉比上次有力气一点。
```

输入：

```text
林林总总：今天开始研究一个新的副业方向，想做本地生活探店内容。
```

如果目录里没有相关主题，技能可能新建：

```text
2026-05-12 本地生活探店副业.md
```

## 安装

项目内的技能源码位于：

```text
skills/llzz
```

Codex 的本机技能目录通常是：

```text
/Users/ziheng/.codex/skills/llzz
```

安装或同步：

```bash
cd /Users/ziheng/Projects/llzz-skill
zsh scripts/install.sh
```

脚本默认会把 `skills/llzz` 同步到：

```text
/Users/ziheng/.codex/skills/llzz
```

如果目标目录已存在，脚本会先把旧目录移动为带时间戳的备份，再复制项目内版本。因此请把这个项目当作技能的源文件仓库。

## 验证

安装后检查：

```bash
test -f /Users/ziheng/.codex/skills/llzz/SKILL.md
test -f /Users/ziheng/.codex/skills/llzz/agents/openai.yaml
```

查看触发描述：

```bash
sed -n '1,40p' /Users/ziheng/.codex/skills/llzz/SKILL.md
```

检查 Obsidian 目标目录：

```bash
test -d "/Users/ziheng/Library/Mobile Documents/iCloud~md~obsidian/Documents/笔记个人/林林总总"
```

## 使用建议

推荐输入方式：

```text
llzz 记一下：今天状态一般，肚子还是有点撑，晚上早点睡。
```

```text
林林总总：今天练胸，推胸感觉动作还不稳定，下次问一下教练。
```

```text
把这张截图整理到林林总总
```

为了让 AI 更准确判断追加还是新建，可以在输入里补充：

- 这是接着哪件事。
- 是否和之前某篇笔记有关。
- 是否希望单独成篇。
- 是否只是随手记。

## 维护规则

更新技能时，优先修改：

```text
skills/llzz/SKILL.md
```

如果技能名称、简介、默认 prompt 变化，再同步修改：

```text
skills/llzz/agents/openai.yaml
```

修改后运行安装脚本：

```bash
zsh scripts/install.sh
```

## 产品优化方向

后续可以继续增强：

1. 周总结：自动从“林林总总”目录提取一周内的健康、生活、待办趋势。
2. 主题索引：生成 `林林总总索引.md`，把健康、健身、装修、复盘等主题聚合起来。
3. 健康观察：连续出现腹胀、睡眠差、乏力等内容时，生成提醒和观察清单。
4. 标签规范：统一 `#健康`、`#健身`、`#饮食`、`#睡眠`、`#装修`、`#复盘`。
5. 图片归档：截图转写后保存原始摘录，并尽量生成可搜索摘要。

## 当前边界

`llzz` 是记录助手，不是专业诊断、法律意见或财务建议工具。涉及身体不适、医疗判断、法律风险或资金决策时，它可以帮助保存和整理记录，但不能替代专业人士。
